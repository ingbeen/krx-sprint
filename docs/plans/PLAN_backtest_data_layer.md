## 3) 배경/맥락(Context)

### 현재 문제점 / 동기

- 현재 로더는 파일 단위다(1단 일자별 1,857 파일 / 2단 종목별 3,136 파일). 백테스트는 "전 기간 × 전종목" 패널을 요구하며, 매 실행마다 조인·플래그 계산을 반복하면 파라미터 스윕이 불가능하다.
- 수집 단계에서 확정된 처리 규칙(거래정지·상장주식수 급변·수정 미반영·이전상장 절단·정규장 미형성)이 **문서에만 있다**. 소비 코드가 하나라도 빠뜨리면 성과가 조용히 부풀려진다. 규칙을 데이터에 박아 구조적으로 강제한다.
- 원본가와 수정주가를 혼용하면 신호가 오염된다. 특히 **2단 거래량은 1,147종목에서 조정돼 있어** 거래대금 계산에 쓰면 안 된다. 컬럼을 만들지 않는 것이 가장 확실한 차단이다.
- 비용(수수료 + 증권거래세 + 슬리피지)은 단타 전략의 순기대값 부호를 가른다. 세율은 기간 중 여섯 번 바뀌었고 적용 기준이 결제일이라 오프바이원이 나기 쉽다.
