# reference — 패턴 참고용 원본 (실행 코드 아님)

기존 quant(QBT) 프로젝트에서 가져온 참고용 원본이다.
그대로 사용하지 않고 **패턴만 참고**해 krx-sprint 용으로 재작성한다. 재작성 완료 후 이 폴더는 삭제해도 된다.

| 파일 | 참고할 패턴 |
|---|---|
| `stock_downloader.py` | 다운로드 → 엄격한 검증(결측/0값/음수/급등락) → 통과 시에만 저장, 검증 실패 시 즉시 예외(보간 금지) |
| `data_loader.py` | 중앙 집중식 로딩(파일 존재 확인 → 필수 컬럼 검증 → 날짜 파싱 → 정렬 → 중복 제거) |

주의: 두 파일 모두 `qbt` 패키지 import가 남아 있어 이 프로젝트에서는 실행되지 않는다.
pyright/ruff 검사 대상에서도 제외되어 있다(열람 전용). 이 폴더를 삭제할 때 pyproject.toml의
`extend-exclude = ["reference"]` 설정도 함께 제거한다.
원본은 기존 quant 저장소(`src/qbt/utils/`)에 그대로 있으므로 삭제 후에도 언제든 다시 참조할 수 있다.
