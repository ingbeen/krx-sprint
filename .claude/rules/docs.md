# docs 폴더 규칙

`docs/`는 krx-sprint의 개발/운영 문서와 변경 계획서(Implementation Plan)를 관리한다.

## docs/archive 정책

- `docs/archive`는 과거 문서 보관용이다.
- 현재 작업의 규칙/근거/소스 오브 트루스(SoT)로 **사용하지 않는다**.
- 현행 규칙의 기준은 루트 `CLAUDE.md` + 작업 범위 도메인 `CLAUDE.md` + 최신 plan 뿐이다.

## 계획서

계획서 작성·갱신 절차는 `/plan` 스킬이 SoT다. 계획서를 만들거나 고칠 때 해당 스킬을 따른다.
